Privacy and terms

What happens to your files

  • The file you upload is written to a temporary folder on the server only for the duration of the conversion and is deleted as soon as the conversion ends, whether it succeeded or not.
  • The converted .docx is kept so you can download it, for at most the retention time shown on the main page (usually 15 minutes). It is deleted after that, or sooner if the server restarts or stops when idle.
  • Files are never copied anywhere else, never inspected by a person and never used to train anything.
  • If a PDF needs a password, the password is used only to open that file during the conversion. It is not stored or logged.

What is logged

  • Your IP address is kept in memory to enforce the per-address rate limits and appears in server request logs.
  • Failed conversions are logged with a job id, the file type and the error category. File names and file contents are not logged.
  • No cookies, no accounts, no analytics and no requests to third-party services from the page.

Limits and fair use

The service is free and runs on a small machine. Uploads are capped in size and page count, one file converts at a time, and each address gets a limited number of conversions per minute and per day. Addresses that abuse the service may be blocked.

No warranty

The converter is provided as is, without any warranty. Conversion quality depends on the input; always check the result before relying on it. Do not upload files you are not allowed to process on a third-party server.
